# ONO3P / L61P 点击花费出单速度

一个无需安装的单页工具，用中国时间和德国时间对照记录 ONO3P、L61P 的累计点击、花费和出单，并计算时段速度、预估 CPC、点击达标、预计收盘值和当日投放余量。

## 使用

1. 在中国时间 14:30 的起点填写累计点击、累计花费、累计总单和累计广告单。
2. 按小时填写下一时段的累计值。
3. 自然单由「总单 − 广告单」自动计算，不单独录入。
4. 在「点击达标与投放」里填写每日最高广告额度、CPA 和实际花费，判断今天还能投放还是已经超支。
5. 按小时填写日均订单与每单所需点击，页面会计算目标点击并标出「达标」「不达标」。
6. 可保存版本、导出当天 CSV、导出完整备份，并从历史版本恢复。

## 数据说明

- 页面不包含任何公司业务数据。
- 所有录入值、参照目标和版本只保存在访问者当前浏览器的本地存储中。
- 清除浏览器站点数据会删除本地记录，重要记录请先导出备份。
- 本工具不连接广告平台或 ERP，也不会自动采集数据。

## 计算口径

- 点击速度、花费速度、总单速度、广告单速度和自然单速度都按两次累计值之差除以间隔小时数。
- 预估 CPC = 预计收盘花费 ÷ 预计收盘点击。
- 广告占比 = 累计广告单 ÷ 累计总单。
- 德国时间按欧洲柏林时区自动处理夏令时。
- 按单量允许花费 = 当前累计总单 × CPA。
- 最终允许花费 = min（按单量允许花费，每日最高广告额度）。
- 还能投放金额 = 最终允许花费 − 当前实际广告花费；结果为负数时显示已超出金额。
- 每小时目标点击 = 每小时日均订单 × 每单所需点击；默认每单 33.3 次点击，可修改。
