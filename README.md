# ONO3P / L61P 点击花费出单速度

一个无需安装的单页工具，用中国时间和德国时间对照记录 ONO3P、L61P 的累计点击、花费和出单，并计算时段速度、预估 CPC、点击效率、利润花费上限、预计收盘值和当日投放余量。

页面中的所有金额均按欧元（EUR）录入、计算和展示。

旧版保存的人民币最高额度和人民币实际花费不会自动当成欧元；升级后请按广告后台的欧元数值重新填写一次。

## 使用

1. 在中国时间 14:30 的起点填写累计点击、累计花费、累计总单和累计广告单。
2. 按小时填写下一时段的累计值。
3. 自然单由「总单 − 广告单」自动计算，不单独录入。
4. 在「点击与投放」里填写欧元每日最高广告额度、欧元 CPA、欧元目标 CPC 和欧元实际花费；最高额度可以留空，页面会先按 CPA 判断。
5. 页面的第二张表直接读取「今日盯盘」里的累计点击，自动计算相邻两次累计值之间的新增点击；历史转化只用于对照，不单独决定是否达标。
6. 第二张表下方会列出各时点的累计点击参考上限，用累计总单 × CPA ÷ 目标 CPC 自动计算。
7. 「ONO3P 今日投放判断」顶部展示当前时间、当前累计点击、实际花费、CPC 与按花费应有点击；红黄绿分别表示点击过慢、需要关注、速度达标，并给出对应检查方向。
8. 可保存版本、导出当天 CSV、导出完整备份，并从历史版本恢复。

## 数据说明

- 页面不包含任何公司业务数据。
- 所有录入值、参照目标和版本只保存在访问者当前浏览器的本地存储中。
- 清除浏览器站点数据会删除本地记录，重要记录请先导出备份。
- 本工具不连接广告平台或 ERP，也不会自动采集数据。

## 计算口径

- 点击速度、花费速度、总单速度、广告单速度和自然单速度都按两次累计值之差除以间隔小时数。
- 预估 CPC = 预计收盘花费 ÷ 预计收盘点击。
- 广告占比 = 累计广告单 ÷ 累计总单。
- 德国时间按欧洲柏林时区自动处理夏令时。
- 按单量允许花费 = 当前累计总单 × CPA。
- 最终允许花费 = min（按单量允许花费，每日最高广告额度）。
- 还能投放金额 = 最终允许花费 − 当前实际广告花费；结果为负数时显示已超出金额。
- 当前实际点击至少应达到 = 当前实际广告花费 ÷ 目标 CPC；低于这个数表示点击偏少、CPC 偏高。
- 利润上限内最多点击 = 最终允许花费 ÷ 目标 CPC；它是花费封顶时可买到的点击上限，不是必须全部买满。
- 各时点累计点击参考上限 = 该时点累计总单 × CPA ÷ 目标 CPC。
- 实际累计点击低于时点参考上限，只表示没有把允许的点击全部买满，不等于不达标。实际 CPC 不高于目标 CPC、花费又在 CPA 帽内时，用更少点击换到更多单是更好的转化。
- 实际累计点击高于参考上限也不单独判异常；如果实际 CPC 更低、总花费仍在单量 CPA 帽内，多买到点击同样正常。
- 当前 CPC = 当前实际广告花费 ÷ 当前累计点击。
- 实时点击速度判断按“当前花费 ÷ 目标 CPC”计算应有点击：实际点击低于应有点击 10% 以上标红，只差不到 10% 标黄；达到或超过应有点击、且花费不超单量帽时标绿。花费超过单量帽也会标红。点击记录超过 75 分钟未更新时标黄，提醒补录。
- 历史参考新增 = 每小时日均订单 × 历史转化参考；默认每单 33.3 次点击，只用于对照历史转化，不是达标硬线。
- 如果「历史转化参考 × 目标 CPC」高于 CPA，页面会提示目标口径冲突，并给出按 CPA 与目标 CPC 反推的每单最多点击和最低 CVR。
- 历史同期订单进度使用手动填写的 24 小时日均订单累计；没有完整基准时不猜订单快慢。
